Politique de confidentialité

Cette politique de confidentialité explique comment le Musée HOP WW2 collecte, utilise et protège les données des visiteurs conformément au RGPD (Règlement Général sur la Protection des Données).

1. Nature du site

Le Musée HOP WW2 est un site historique et éducatif consacré à la Seconde Guerre mondiale. Aucun contenu n’a vocation propagandiste : toutes les informations sont strictement historiques, contextualisées et destinées à la compréhension des événements du conflit.

2. Données collectées

Le site ne collecte aucune donnée personnelle automatiquement. Aucune inscription, aucun compte utilisateur, aucun suivi nominatif n’est utilisé.

3. Formulaire de contact

Le formulaire de contact utilise le service Formspree. Lorsque vous envoyez un message, les données suivantes sont transmises :
• Nom (champ rempli par le visiteur)
• Email (champ rempli par le visiteur)
• Message (contenu écrit par le visiteur)

Ces informations sont utilisées uniquement pour répondre aux demandes. Elles ne sont jamais revendues, partagées ou utilisées à des fins commerciales.

4. Hébergement

Le site est hébergé par GitHub Pages. GitHub peut collecter des données techniques anonymes (logs, sécurité, trafic) nécessaires au fonctionnement du service.

5. Cookies et mesure d’audience

Le site peut utiliser Google Analytics pour mesurer l’audience. Google Analytics peut déposer des cookies anonymes permettant d’analyser les visites. Vous pouvez désactiver ces cookies via les paramètres de votre navigateur.

6. Protection des données

Le Musée HOP WW2 ne stocke aucune donnée personnelle sur ses serveurs. Les messages envoyés via le formulaire sont traités de manière confidentielle.

7. Contenu sensible

Le site traite de sujets liés à la Seconde Guerre mondiale. Aucun contenu n’a pour but de promouvoir un régime, une idéologie ou un symbole. Il s’agit d’un travail historique, mémoriel et éducatif.

8. Contact pour les données personnelles

Pour toute question concernant vos données, vous pouvez contacter le responsable via la page Contact.

Cette page n’a aucune vocation propagandiste. Elle présente des informations légales et historiques dans un cadre éducatif.
