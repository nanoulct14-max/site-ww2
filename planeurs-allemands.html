Planeurs allemands

Les 10 modèles militaires de la Luftwaffe

L’Allemagne développe plusieurs planeurs militaires durant la Seconde Guerre mondiale. Utilisés pour le transport de troupes, de matériel ou pour des missions spéciales, ces appareils silencieux jouent un rôle important dans les opérations aéroportées. Voici les 10 planeurs militaires allemands produits ou testés entre 1937 et 1945.

DFS 230

  • Type : planeur d’assaut
  • Capacité : 8 à 10 soldats
  • Structure : bois + toile
  • Longueur : 11 m
  • Envergure : 21 m
  • Vitesse remorquée : ≈ 190 km/h
  • Remorquage : Ju 52, He 111, Do 17

DFS 331

  • Type : planeur cargo lourd
  • Capacité : matériel volumineux
  • Statut : prototype
  • Structure : bois
  • Rôle : transport logistique

Focke‑Achgelis Fa 225

  • Type : planeur expérimental
  • Particularité : voilure tournante
  • Capacité : 1 pilote
  • Statut : 1 exemplaire construit

Gotha Go 242

  • Type : planeur de transport
  • Capacité : 23 soldats
  • Structure : acier + toile
  • Particularité : portes arrière pour chargement

Gotha Go 244

  • Type : version motorisée du Go 242
  • Moteurs : 2 moteurs radiaux
  • Rôle : transport aérien autonome

Gotha Go 345

  • Type : planeur de transport
  • Statut : prototype
  • Objectif : remplacer le DFS 230

Gotha Ka 430

  • Type : planeur léger
  • Capacité : 12 soldats
  • Rôle : opérations rapides

Junkers Ju 322 Mammut

  • Type : planeur géant
  • Capacité : ≈ 140 soldats
  • Structure : bois
  • Statut : abandonné (problèmes structurels)

Messerschmitt Me 321 Gigant

  • Type : planeur lourd
  • Capacité : 120 soldats ou véhicules
  • Remorquage : He 111, Me 110 (tandem)
  • Particularité : le plus grand planeur allemand

Blohm & Voss BV 40

  • Type : planeur chasseur
  • Particularité : pilote allongé pour réduire la silhouette
  • Armement : 2 canons de 30 mm
  • Statut : prototype
